📋 Sequence: Reservation — System-assigned Mode

sequenceDiagram actor Driver participant Kong as Kong Gateway participant Search as Search Service participant Reservation as Reservation Service participant Redis as Redis Cluster participant RMQ as RabbitMQ participant Worker as Queue Worker participant Billing as Billing Service participant DB as PostgreSQL Driver->>Kong: POST /v1/reservations (mode=system_assigned, type=CAR) Kong->>Reservation: gRPC CreateReservation(SYSTEM_ASSIGNED, vehicle_type) Reservation->>Redis: GET idempotency:{key} alt Duplicate request Redis-->>Reservation: existing reservation_id Reservation-->>Kong: ReservationResponse (idempotent) Kong-->>Driver: 200 existing reservation else New request Reservation->>Search: gRPC GetFirstAvailable(vehicle_type) Search->>Redis: GET availability:{type} (cache) alt Cache miss Search->>DB: SELECT spot WHERE status=AVAILABLE LIMIT 1 DB-->>Search: spot_id end Search-->>Reservation: spot_id Reservation->>RMQ: Publish booking.exchange routing_key=spot_id RMQ->>Worker: Route by consistent hash Worker->>Redis: SETNX lock:{spot_id} TTL 1h alt Lock acquired Worker->>DB: INSERT reservation (status=RESERVED) Worker->>Billing: gRPC ChargeBookingFee(5000) Billing-->>Worker: OK Worker-->>Reservation: ReservationResponse Reservation-->>Kong: spot_id + qr_code Kong-->>Driver: 201 pay 5.000 IDR booking fee else Lock failed Worker->>Search: retry next available end end

📋 Sequence: Reservation — User-selected Mode

sequenceDiagram actor Driver participant Kong as Kong Gateway participant Search as Search Service participant Reservation as Reservation Service participant Redis as Redis Cluster participant RMQ as RabbitMQ participant Worker as Queue Worker participant Billing as Billing Service participant DB as PostgreSQL Driver->>Kong: GET /v1/availability?floor=1&type=CAR Kong->>Search: gRPC GetAvailability(floor, type) Search-->>Kong: AvailabilityResponse Kong-->>Driver: 200 spots list Driver->>Kong: POST /v1/spots/{spot_id}/hold Kong->>Reservation: gRPC HoldSpot(spot_id, driver_id) Reservation->>Redis: SETNX hold:{spot_id} TTL 60s alt Hold acquired Reservation-->>Kong: HoldResponse OK Kong-->>Driver: 200 spot held for 60s else Already held Reservation-->>Kong: SPOT_HELD error Kong-->>Driver: 409 spot held, try another end Driver->>Kong: POST /v1/reservations (mode=user_selected, spot_id) Kong->>Reservation: gRPC CreateReservation(USER_SELECTED, spot_id) Reservation->>Redis: GET hold:{spot_id} alt Hold valid Reservation->>RMQ: Publish booking.exchange routing_key=spot_id RMQ->>Worker: Route by consistent hash Worker->>Redis: SETNX lock:{spot_id} TTL 1h alt Lock acquired Worker->>Redis: DEL hold:{spot_id} Worker->>DB: INSERT reservation (status=RESERVED) Worker->>Billing: gRPC ChargeBookingFee(5000) Worker-->>Reservation: ReservationResponse Reservation-->>Kong: parking lot ID + qr_code Kong-->>Driver: 201 pay 5.000 IDR else Lock failed Worker-->>Reservation: SPOT_TAKEN Kong-->>Driver: 409 Spot taken end else Hold expired Reservation-->>Kong: HOLD_EXPIRED Kong-->>Driver: 409 re-select spot end

📋 Sequence: Check-in via Presence Service

sequenceDiagram actor Driver participant Kong as Kong Gateway participant Presence as Presence Service participant Reservation as Reservation Service participant Billing as Billing Service participant DB as PostgreSQL participant Redis as Redis Cluster Driver->>Kong: POST /v1/checkin (reservation_id, spot_id) Kong->>Presence: gRPC CheckIn(reservation_id, spot_id) Presence->>Reservation: gRPC GetReservation(reservation_id) Reservation-->>Presence: reservation (reserved spot_id) alt Correct spot Presence->>Reservation: gRPC CheckIn(reservation_id, spot_id) Reservation->>DB: UPDATE reservation SET status=ACTIVE Reservation->>Redis: DEL lock:{spot_id} Reservation-->>Presence: OK Presence->>Billing: gRPC StartBillingSession(reservation_id) Billing->>DB: UPDATE billing SET session_start=now() Billing-->>Presence: OK Presence-->>Kong: CheckInResponse (status=ACTIVE) Kong-->>Driver: 200 check-in confirmed, billing started else Wrong spot Presence-->>Kong: BLOCKED Kong-->>Driver: 409 must park at assigned spot end

📋 Sequence: Billing & Checkout — Pay Before Exit

sequenceDiagram actor Driver participant Kong as Kong Gateway participant Billing as Billing Service participant Payment as Payment Service participant DB as PostgreSQL Driver->>Kong: POST /v1/checkout (idempotency-key: uuid) Kong->>Billing: gRPC Checkout(reservation_id, idempotency_key) Billing->>DB: SELECT billing WHERE reservation_id=? DB-->>Billing: session_start, session_end=now() Billing->>Billing: Calculate hourly fee (ceil hours * 5000) Billing->>Billing: Count midnight crossings (crossings * 20000) Billing->>Billing: total = max(0, hourly + overnight - booking_fee) Billing->>DB: INSERT invoice (total, status=PENDING) Billing->>Payment: gRPC CreatePayment(invoice_id, amount, QRIS) Payment->>Payment: Generate QR code (Pondo Ngopi) Payment-->>Billing: PaymentResponse (qr_code, status=PENDING) Billing-->>Kong: InvoiceResponse (qr_code) Kong-->>Driver: 200 QR code — scan to pay Note over Payment: Driver scans QR and pays alt Settlement PAID Payment->>DB: UPDATE payment SET status=PAID Note right of Driver: Gate opens — driver exits else Settlement FAILED Payment->>DB: UPDATE payment SET status=FAILED Note right of Driver: Gate closed — retry payment end

📋 Sequence: Cancellation Flow

sequenceDiagram actor Driver participant Kong as Kong Gateway participant Reservation as Reservation Service participant Billing as Billing Service participant Redis as Redis Cluster participant DB as PostgreSQL Driver->>Kong: DELETE /v1/reservations/{id} Kong->>Reservation: gRPC CancelReservation(reservation_id) Reservation->>DB: SELECT reservation WHERE id=? AND status=RESERVED DB-->>Reservation: reservation (confirmed_at) Reservation->>Reservation: Calculate elapsed since confirmed_at alt elapsed lte 2 minutes Reservation->>Billing: gRPC ApplyCancellationFee(0) else elapsed gt 2 minutes Reservation->>Billing: gRPC ApplyCancellationFee(5000) end Billing->>DB: UPDATE billing_record (cancellation_fee) Billing-->>Reservation: OK Reservation->>DB: UPDATE reservation SET status=CANCELLED Reservation->>Redis: DEL lock:{spot_id} Reservation-->>Kong: CancelResponse Kong-->>Driver: 200 cancelled

📋 Sequence: Reservation Expiry (No-show)

sequenceDiagram participant Worker as Expiry Worker participant Redis as Redis Cluster participant DB as PostgreSQL participant Notif as Notification Service Note over Worker: Background worker polls every 30s Worker->>DB: SELECT reservations WHERE status=RESERVED AND expires_at lt now() DB-->>Worker: expired reservation records alt status still RESERVED (no check-in within 1 hour) Worker->>DB: UPDATE reservation SET status=EXPIRED Note right of Worker: No additional penalty - driver forfeits booking fee only Worker->>Redis: DEL lock:{spot_id} Worker->>Notif: publish reservation.expired Note right of Worker: Spot released back to inventory else already ACTIVE or COMPLETED Worker->>Worker: skip, no action needed end
